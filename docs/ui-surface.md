# 桌面翻译工作区

Mode: Operate

用户的主要任务是输入或导入文字、选择目标语言与专业领域、翻译、检查和导出。此次优化覆盖文本翻译、文档翻译、术语、历史与设置；基于既有 WPF 视觉风格细化。

优先级：增加原文和译文的可用阅读空间，统一字号与控件状态，保证设置的保存操作可达，并让键盘操作和小窗口使用更清晰。

验证使用真实 WPF 窗口渲染、已有模拟 API 流程和合成文档。覆盖 1080 × 740、1280 × 840、1600 × 1000 逻辑窗口，另生成 144 DPI 渲染图；设置页检查长内容滚动后保存按钮仍在视野内。键盘焦点、术语与历史选中操作也经过交互检查。模拟的 144 DPI 图片用于查看高分辨率输出，不等同于在不同 Windows 缩放设置下的实机测试。

主题色对比度计算：正文在白色上为 11.73:1，辅助文字为 5.52:1，弱化文字在工作区背景上为 4.65:1，白字在主按钮上为 5.26:1。测试截图使用模拟译文，不代表真实模型质量，也不包含实际密钥或个人翻译记录。
